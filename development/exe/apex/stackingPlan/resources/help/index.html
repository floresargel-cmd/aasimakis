Production plan software help

Main Window

Basket production layout

Displays the future production of profiles and the way that they will be stacked given the profiles produced according to the planned production layout and the settings of each profile.

Planned production layout

Displays the future profile production.

Basket Layout

Use mouse wheel to zoom

Profile Layout

 

Use mouse wheel to zoom

Double check box: if checked the profiles are stacked in double length mode

Angle spin box: rotates the profile shape to much the angle in which the profile comes out from the die

Layer spacing: the minimum vertical spacing that the profile needs. If this is not zero then the software will put the layer in the next comb that has vertical distance more than the defined value.

Profile spacing: the horizontal distance between to nearby profiles

Profile multiplicity: the number of the profiles that the given dxf drawing has.

In comb check box: if checked the profiles will be put into combs

Calculate button: sets the spacers according to the default mode

Spacers check buttons (1:8): override the default layout of the spacers

Shortcuts

·         F1 displays this help file.

·         Ctrl+F5 calculates the profiles stacking into the baskets and reloads the planned production from the database if this is needed

·         Ctrl+Left arrow moves the selected profile production one place to the left. Active only if a profile production is selected

·         Ctrl+Right arrow moves the selected profile production one place to the right. Active only if a profile production is selected

·         Ctrl+O displays the options dialog

·         Ctrl+C displays the PLC communications dialog
